# 02　Python 与金融数据

从原接口或配套 CSV 得到有序的行情表，能解释证券、日期、价格、成交量与复权字段。

从两天的收盘价算出第一条日收益。若两只股票的交易日并不完全相同，先按证券与日期对齐，再计算变化；直接按行号拼接可能把不同日期算成同一天。Quant-for-Beginners 用 OHLCV 表比较资产，WhaleQuant 用澳航 Qantas 的 CSV 练习索引、分组、连接与布尔筛选。

分别保留 BaoStock 的日线、指数成分及季度财务接口，以及 Tushare、yfinance 的原实验。API 返回空表、文件缺列和休市分别有不同含义。用同一证券检查字段单位、交易日期和复权选项，再把行情与基本面表按各自的可用时间连接。

pandas 配套脚本覆盖 Series、DataFrame、时间索引、CSV、NumPy 和文件操作。做 joins 之前先写下期望的键与行数；抽一行手算，辨别数值相同究竟来自市场还是重复连接。
