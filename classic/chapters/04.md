# 04　因子与选股

从经济假设构造截面因子，并在统一的信息时点检验单因子、多因子和中性化后的排序。

择股先固定一天和当时有资格入池的股票。按信号排序后，只用随后形成的收益评价。把多天的数据混在一起计算一次相关系数，会同时混入市场涨跌和股票间差异。

WhaleQuant 从效用、MPT、CAPM 与 APT 建立因子模型，再分别构造日频和高频因子。比较排序相关、分组收益和行业或市值中性化前后的暴露。若成交明细是因子的输入，仅有日线时无法恢复原定义。

多因子 Python 实战沿用原样本与目标。把标准化器放在训练段拟合，保留股票与日期键用于还原预测；记录原示例所依赖的 stock_data.csv 和实际运行状态。

原多因子练习使用 PE、PB、ROE 解释 Returns，并以预测值大于 0.1 筛选股票。原材料未规定 Returns 的持有期，补数据时首先需要澄清这一列的时间含义；固定原示例的随机切分后，可以另外讨论时间切分会如何改变可解释性。
