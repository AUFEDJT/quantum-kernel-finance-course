# 停牌与缺失处理

本节将真实停牌引起的缺失作为数据建模问题处理。上版的连续121个市场日完整门槛使3条评价记录无法进入实验；该记录保留。新版本允许在市场日网格上保留原始缺失，先计算能定义的特征，再在训练资料内拟合特征层的填补规则。它不会制造停牌日的交易价格或成交量。

本课采用Qlib启发的缺失处理，并保留自己的80特征、mRMR、角度缩放和固定标签。不是运行完整Alpha158，也不把本课配置说成Qlib的通用默认值。固定依据为Microsoft Qlib提交`54355232463878d2eebb91fe0ee5fa7fa1f5976c`。

## 学习目标与输入输出

接入C02的数据时间轴、C03的特征定义、C08的量子编码前处理、C09预算、C10审计与C11项目交付。用[解析Notebook](../notebooks/qukernet_cloud_v3/03_停牌与缺失处理.ipynb)区分休市、停牌、来源漏数；检查训练内填补不会访问未来；解释少观测滚动统计的意义与风险。

输入为原始观测、市场日历、字段定义与冻结协议。输出为特征值、缺失掩码、有效支持数、训练期变换对象和按区间汇总的缺失率。真实逐样本记录留在私有目录，公开课程仅保留获准汇总与解析功能演示。

## 明确处理顺序

1. 按市场交易日对齐；原始缺失行情保持NA。全市场休市不增加伪交易日。
2. 点值特征要求指定端点有效；滚动统计按冻结的逐项公式与支持规则计算。缺失一段行情不再一律否决整条记录，但少量观测不等于完整窗口。
3. 标签仍取原定次日与第6交易日的开盘。端点无效则标签无效，不顺延、不填0。
4. 只在训练特征中逐列拟合有限值中位数；排除全缺失、常数、零IQR和精确重复特征。记录排除原因，不能复制列充数。
5. 用训练标签实施mRMR，选8项；训练中拟合角度缩放。验证和评价只应用这些冻结对象。
6. 保存80特征及入选8特征的缺失掩码、滚动有效支持数；公开分区汇总，不发布证券逐样本。

正式细节以[版本协议索引](QuKerNet先导实验版本索引.md)链接的机器可读协议和对应实现为准。解析练习使用3日窗口讲机制，正式特征仍使用冻结的1至120日窗口。

## 为什么必须保留掩码与支持数

中位数填补使矩阵可输入模型，但不恢复已经缺失的信息。缺失可能与交易状态或公司事件相关；填补后的相似度也可能改变量子核。应同时报告缺失率、支持数和填补前后的候选覆盖，不能仅报告程序没有NaN。

市场日滚动与“最近N次个股实际成交”不是同一时间尺度。本版本使用市场日网格，不将停牌前后的多日价格变化直接当作一日收益。真实原始价缺乏完整公司行动核验，仍只解释为预测诊断。

## 验收与课堂作业

- 改动评价期特征或标签，训练中位数、所选特征及缩放对象保持不变。
- 在历史窗口内部与目标端点分别放置缺失，核对特征处理和标签拒绝的区别。
- 未观察到的价格与成交量仍为NA；所有填补只发生在模型特征矩阵。
- 对固定50条评价记录公开处理后覆盖和填补比例；不为通过验收更换股票或日期。
- 解释为什么4条评分器训练标签、16条核训练记录与50只股票的历史覆盖是不同规模。
