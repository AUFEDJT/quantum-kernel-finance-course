# 本地离线验证环境

本记录对应2026年11月15日执行本轮离线测试、独立解析数值检查和教学Notebook的本地Windows CPU环境。Python为64位CPython 3.12.14。

| 依赖 | 实际安装版本 |
|---|---|
| NumPy | 2.3.5 |
| SciPy | 1.18.1 |
| pandas | 3.0.1 |
| scikit-learn | 1.7.2 |
| matplotlib | 3.10.7 |
| nbformat / nbclient | 5.10.4 / 0.10.2 |
| ipykernel | 6.30.1 |
| pytest | 8.4.2 |
| PyTorch / Cqlib | 本环境未安装 |

[完整版本记录](local_offline_environment.json)列出实际安装的79项发行包；[版本固定清单](requirements-local-offline.lock.txt)记录相同版本。清单不包含安装源、私有路径或机器账户信息。这是已安装环境的版本记录，尚未通过全新环境重装验证，也未包含wheel哈希；其他操作系统上的可安装性需要重新核验。

控制流测试使用明确标注的模拟概率提供器和评分器；参数移位与KTA的数值检查使用独立的解析构造线路。Notebook只读取公开协议、状态和已有汇总。通过这些检查不表示神经评分器已在本环境训练、天衍已可调用，或股票预测有效。

在课程根目录切换至实验模块后，可以执行离线检查：

```text
cd experiments/qukernet_finance
python -m unittest discover -s cloud_v3/tests -v
```

独立数值检查的公开实现见[numerical_checks.py](numerical_checks.py)。在同一实验模块目录显式运行：

```text
python -m cloud_v3.numerical_checks
```

默认只打印JSON，核对两种态演化、重叠概率、双端参数移位、KTA链式梯度及参数重载。三个固定例子全部是解析构造；其中单编码块、一层线路的共享参数梯度应为零。程序不接受金融数据、不登录平台、不提交任务，也不由教学Notebook自动调用。

本记录不作为无影或天衍运行环境的锁定依据。正式云执行还需要另存实际部署的Python、PyTorch、Cqlib及依赖版本、代码哈希和运行记录；以该次部署核验结果为准。
