# 50只股票与3小时云端方法先导

本模块实施50股、3小时的缩规模协议。当前版本为 **Qlib missing v1**，固定使用2019年至2026年3月25日的数据，保留此前冻结的50股、32条训练验证键和50条股票—日期评价配对；量子核训练16条、验证16条、评价50条。全训练期合格历史用于80项特征中的8项选择与缩放。因此，“覆盖50只股票”与“核模型用50只股票的全部历史训练”含义不同。

## 教学目标

学习者应能够区分神经评分器预测KTA、KTA本身、验证准确率与后续日期预测准确率，能够复算测量预算，并解释微调改善训练目标为何未必改善预测。

完整方法阶段为线路生成、核对齐测量、神经评分、候选筛选、参数更新与下游预测。先导仅使用4条评分器训练标签、2条诊断标签和一个微调配置；它不能验证可靠的神经排序泛化，也没有多配置验证选优。

## 数据与解释边界

股票池按验证开始前可知的信息、交易所比例和固定种子选定，不根据未来完整性补股。评价日期与股票配对先冻结，每股只安排一次评价。原始行情NA保持不变；标签端点无效仍阻止启动，历史特征缺失按新版逐项规则和训练内预处理处理。固定截止日前63个标签成熟日期为评价区间，之前63日为验证原区间，训练从2019年起；全部跨界标签净化。当前资格锚点为2025年9月2日，评价信号日范围为2025年12月9日至2026年3月17日。

公司行动与成交口径未完成核验，标签继续作为原始价格预测诊断。结果不作为策略净收益、未来盈利或量子优势证明。主指标按日期等权，50条记录不视为50个独立市场日期。当前协议见[protocol_cutoff_20260325_qlib_missing_v1.json](protocol_cutoff_20260325_qlib_missing_v1.json)，[连续历史旧版](protocol_cutoff_20260325.json)与[原协议](protocol.json)分别保留。

数据准备入口使用显式参数`--cutoff-date 2026-03-25`；指定日无实际记录时停止，不自动后退。完整源文件哈希与使用区间哈希分别记录，截止日之后的正常行情变化不得影响模型输入。停牌处理已在新版本中明确：[停牌与缺失教案](../../../docs/停牌与缺失处理_qlib_missing_v1.md)说明机制与来源；这不是行情填补或完整Alpha158复刻。

初值和微调终点的核分别以独立512-shot测量估计，并分别重新拟合SVC。因此单次预测差值同时包含参数更新和测量随机性，不能直接解释为纯粹的微调因果收益。日期块bootstrap仅重采样已得到的配对预测；它不重新抽测量读数，也不更换搜索种子，因而没有覆盖这两类不确定性。

日期块按10个实际评价日期的排序取相邻非循环块，不是连续市场交易日；每日期5只不同股票、每股只评价一次。区间仅描述该固定样本条件下的探索性不确定性。

## 复现方式

默认教学Notebook只读公开的预算、状态和已有汇总，不读取实验室数据、不登录天衍、不自动提交任务。正式执行需要私有数据、当前账户证据、同一规范账本及显式启动开关；凭据通过安全输入留在进程内。

含本次续跑子窗口的账本须由`cloud_v3.completion_ledger`读取；旧仅识别3小时窗口的runner/ledger不能直接重启或新建实验。本次子窗口默认单次且不自动恢复，后续实验需要新的明确协议与兼容账本的准入。

公开读者有三种不同入口：

1. **离线解析教学**：03和04使用明确标注的构造输入，05只读取获准汇总，任何读者可在独立教学环境运行。
2. **获授权的原数据重放**：需要原冻结32条训练验证键、50条股票—日期配对、原数据来源身份及使用区间哈希。`prepare`所需日历、来源证明和冻结记录属于私有输入；公开仓库不提供这些受限金融数据。
3. **自有合法数据研究**：先建立自己的数据许可、时间划分、选样、日历和哈希，再形成新的冻结协议与兼容清单。现有严格执行器不能直接接受任意替换CSV；自有数据运行应称新的迁移实验，不能宣称重放了本版冻结样本。

在课程根目录运行离线检查：

```text
python -m pytest experiments/qukernet_finance/cloud_v3/tests -q
```

本地离线检查使用独立Python 3.12环境，版本记录见本目录的环境清单。该环境未安装Torch或Cqlib，涉及接口的测试使用模拟响应。真实云执行使用无影上的独立研究环境与Cqlib 1.3.11，实际依赖锁和部署清单另存；不能把本地离线环境记作已验证的云运行环境。
